# Disaster Duty Assignment and Notification System (DDANS) 🚨

A specialized management platform designed to streamline emergency response by automatically assigning roles to personnel during disasters. This system ensures rapid mobilization through real-time notifications, bridging the communication gap between authorities and field responders.

## 🌟 Key Features
* **Automated Duty Assignment:** Logic-based role allocation based on disaster type and personnel availability.
* **Real-Time Notifications:** Instant alerts to field staff for immediate deployment.
* **Admin Dashboard:** Centralized control for authorities to monitor resources and active duty status.
* **Personnel Management:** Comprehensive database management for all response team members.
* **Responsive UI:** Optimized for both desktop (command center) and mobile (field use).

## 🛠️ Tech Stack
**Frontend:** React.js, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Tools:** Git, GitHub, VS Code
